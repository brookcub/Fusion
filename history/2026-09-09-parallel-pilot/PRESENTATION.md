# Parallel pilot interruption repairs

## Why these changes exist

The three-ticket FUSI pilot admitted three concurrent Astra planning sessions,
then created distinct worktrees and started Terra implementation sessions.
Task-bound session telemetry exposed Spark plan reviews despite workflow-owned
Opus configuration. The operator paused the run and preserved task records,
committed identities, uncommitted patches, and untracked source files in an
encrypted, decrypt-verified recovery capsule. No completion is claimed.

## Why the mechanism is better

Workflow prompt sessions now resolve the existing effective-settings overlay
before reading policy, primary/fallback models, or reasoning effort. There is
one settings snapshot, not a new model authority. Task/node overrides and test
mode keep their existing precedence. Forced read-only tools remain authoritative.

The pilot also exposed POSIX quoting passed literally through Windows cmd to
Git. Base refresh now uses argument arrays without a shell. Existing dirty-work
and compensation rules are unchanged; no general worktree cleanup was added.

## Validation before packaging

- Model reproducer: four failures and 21 passes against the unchanged engine.
- Native Git reproducer: three failures against the unchanged refresh helper.
- Combined focused suite: seven files, 63 tests passed.
- Expanded native spaced-path suite: five tests passed, including own-commit
  rebase, conflict abort, dirty-byte preservation, and persistence compensation.
- Trusted merge gate: 177 core, 461 engine, 72 CLI, and 10 private PostgreSQL
  tests passed; the private PostgreSQL gate verified shutdown.
- Independent read-only review found no implementation blocker. Its requested
  model-precedence and native rebase/abort coverage was added and passed.

Full package build, preparation checks, isolated lifecycle rehearsal and live
cutover have separate receipts; this document does not assert their success.
The owning Task System public entrypoint remains the only lifecycle interface.
The paused pilot must resume without clearing completed steps or restoring an
old task snapshot over newer progress. Initial Spark approvals are historical
evidence, not proof that the requested Opus reviewer ran.
